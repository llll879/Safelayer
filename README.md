# SafeLayer Bot 2.0

Telegram-бот для репутации продавцов и отзывов.

Возможности: регистрация продавцов, SafeLayer ID, поиск, рейтинг, положительные/нейтральные/отрицательные отзывы, модерация, подтверждение сделки, жалобы, ответы продавцов, история отзывов, уведомления, правила, помощь, верификация, блокировка и статистика.

## Важное исправление
Включена Telegram HTML-разметка, поэтому `<b>` и `<code>` больше не показываются как обычный текст.

## Render
Создайте Background Worker из GitHub-репозитория. Build: `pip install -r requirements.txt`. Start: `python bot.py`. В Environment добавьте `BOT_TOKEN` и `ADMIN_IDS`.

Также в проекте есть `render.yaml` для автоматической настройки Render.

## Админ-команды
`/admin` ` /reviews` ` /reports` ` /stats` ` /verify SL-ID` ` /block USER_ID`

Не публикуйте токен бота в GitHub.
