# КМБП Base — база Telegram-ботов

Готовая база для сообщества КМБП. Бот позволяет:

- регистрировать проекты/ботов;
- искать бот по @username;
- показывать карточку проекта;
- показывать статус: проверен / предупреждение / плохой бот / заблокирован;
- принимать жалобы из специального чата;
- отправлять жалобы модератору на рассмотрение;
- одобрять или отклонять жалобы кнопками;
- после одобрения показывать подтвержденное нарушение при проверке бота;
- сохранять ссылку на исходную жалобу;
- вести статистику базы;
- вести журнал действий модераторов;
- добавлять ботов вручную;
- добавлять внутренние заметки;
- выдавать карточку проекта для пиара;
- иметь безопасное разделение прав администратора и пользователя.

## Важное ограничение Telegram

Этот бот НЕ может автоматически получить внутреннюю статистику чужого Telegram-бота (количество пользователей, сообщения, активность и т.п.) только по его @username. Telegram Bot API этого не предоставляет.

Поэтому статистика здесь разделена на:
1. **Статистику КМБП** — регистрации, проверки, жалобы, подтвержденные нарушения.
2. **Статистику проекта** — данные, которые владелец/модератор внесли вручную.

Не просите владельцев присылать токены их ботов этому боту без отдельной безопасной инфраструктуры.

## Установка на Termux / Linux

```bash
pkg update
pkg install nodejs
cd ~/KMBP_BOT_BASE
npm install
cp .env.example .env
nano .env
npm start
```

В `.env`:
- `BOT_TOKEN` — токен самого КМБП-бота от @BotFather.
- `ADMIN_IDS` — Telegram ID модераторов через запятую.
- `COMPLAINT_CHAT_ID` — ID специального чата жалоб. Если оставить пустым, жалобы можно создавать командой `/report` из любого чата.

## Основные команды

Пользователь:
- `/start`
- `/check @bot`
- `/search @bot`
- `/register`
- `/report @bot причина`
- `/stats`
- `/help`

Администратор:
- `/admin`
- `/addbot @bot Название | описание`
- `/banbot @bot причина`
- `/unbanbot @bot`
- `/botnote @bot текст`
- `/setstats @bot users=1000,active=250,messages=5000`
- `/logs`

## Жалобы

В специальном чате:

`/report @example_bot Оскорбление пользователя`

Бот создаст заявку и отправит ее администраторам. Модератор выбирает:
- ✅ Подтвердить нарушение
- ❌ Отклонить
- 🔎 Открыть жалобу

При подтверждении бот сохраняет ссылку на сообщение жалобы и показывает ее в карточке бота.

## Рекомендация по модерации

Не называйте проект «плохим» только из-за одной неподтвержденной жалобы. В этой версии метка «Плохой бот» появляется только после решения модератора. В карточке также указывается причина, дата и ссылка на материал.

Для публичной базы лучше использовать формулировку:
**⚠️ Есть подтвержденное нарушение**
вместо бездоказательного обвинения.
