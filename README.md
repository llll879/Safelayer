# SafeLayer Telegram Bot

Полноценный MVP Telegram-бот для отзывов и репутации продавцов.

## Возможности
- Регистрация продавцов
- Поиск продавца по @username или SafeLayer ID
- Профиль продавца с рейтингом и отзывами
- Положительные/нейтральные/отрицательные отзывы
- Ответ продавца на отзыв
- Жалобы на отзывы
- Модерация отзывов и жалоб через админ-команды
- Блокировка пользователей/продавцов
- SQLite база данных
- Защита от повторного отзыва одному продавцу одним пользователем
- Опциональная отметка подтвержденной сделки
- Статистика

## Запуск

1. Создайте бота через BotFather и получите токен.
2. Скопируйте `.env.example` в `.env`.
3. Заполните `BOT_TOKEN` и `ADMIN_IDS`.
4. Установите зависимости:
   `pip install -r requirements.txt`
5. Запустите:
   `python bot.py`

Python 3.10+ рекомендуется.

## Переменные окружения

- `BOT_TOKEN` — токен Telegram-бота
- `ADMIN_IDS` — Telegram ID администраторов через запятую
- `DB_PATH` — путь к SQLite, по умолчанию `safelayer.db`

## Важно

Это готовый рабочий MVP. Для публичного большого проекта желательно добавить PostgreSQL, Redis/rate-limit, резервные копии, отдельную web-admin панель и более строгую систему подтверждения сделок.
